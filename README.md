# HTTPS Handshake Lab — معمل تفاعلي

معمل تفاعلي بالعربي لشرح **إزاي الـ HTTPS بيحمي البيانات**، متصمم لطلبة الصف الثاني الثانوي
(درس 2-1 · Cryptography & Authentication).

صفحة واحدة، من غير أي مكتبات خارجية، تشتغل بالدبل كليك أو من اللينك على طول.

## المحطات الثمانية

| # | المحطة | اللي الطالب بيعمله |
|---|--------|---------------------|
| 1 | ليه محتاجين تشفير؟ | يكتب رسالة ويبدّل بين HTTP و HTTPS ويشوف اللي المهاجم بيقراه |
| 2 | Common-key | يشفّر ويفك بنفس المفتاح، ويغيّر مفتاح المستقبِل فتضيع الرسالة |
| 3 | Public-key | يقفل بالمفتاح العام، ويجرّب يفتح بيه فيفشل |
| 4 | الفرق بينهم | الفخ في الأسماء، جدول «مين معاه إيه»، وتمرين تصنيف من 8 جُمل |
| 5 | الشهادة الرقمية | يغيّر اسم الموقع في الشهادة فالبصمة تتغيّر والتحقق يفشل |
| 6 | المصافحة | محاكاة متحركة على 7 خطوات مع خزنة مفاتيح لكل طرف وصندوق للمهاجم |
| 7 | ليه الاتنين؟ | يقيس سرعة الطريقتين على جهازه ويشوف الفرق |
| 8 | اختبر نفسك | 8 أسئلة بتصحيح وسبب فوري |

## نظام الألوان

اللون هو المفتاح في الشرح كله — ثابت في كل المحطات:

- 🟪 **المفتاح العام** — public key
- 🟧 **المفتاح الخاص** — private key
- 🟦 **المفتاح المشترك** — common key
- 🟥 **المهاجم** — attacker

## ملاحظات للمدرّس

- المحاكاة بتشتغل بتشفير حقيقي جوه الكود، عشان زرار «جرّب تفتح بالمفتاح العام» يفشل فعلًا
  قدام الطلبة — بس الطالب مايشوفش أي معادلات أو أرقام للمفاتيح.
- زرار **«شغّل الكل»** يمشّي المصافحة لوحدها، مناسب للعرض على بروجكتور.
- سهمي ← → في الكيبورد بيتنقلوا بين الخطوات.
- الصفحة بتتماشى مع ثيم الجهاز (فاتح/غامق) وبتشتغل على الموبايل.

## المحتوى

متماشي مع الكتاب المدرسي: المراحل الثلاث بأسماءها
(① Connection · ② Key exchange · ③ Data communication)،
وملاحظة الـ Diffie-Hellman موجودة كبند إضافي مشروح بالألوان من غير رياضيات.
